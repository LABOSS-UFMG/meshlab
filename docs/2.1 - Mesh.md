# `Mesh`

Armazena as coordenadas dos vértices, a conectividade das células e as fronteiras nomeadas de uma malha em duas ou três dimensões. A malha é criada vazia e cresce à medida que os vértices e as células são adicionados.

```python
meshlab.core.Mesh(
    dim=2,
    vertices_capacity=1000,
    cells_capacity=1000,
    increase_ratio=1.5,
    float_dtype=np.float64,
    int_dtype=np.int32,
)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `dim` | `{2, 3}` | `2` | Número de coordenadas por vértice. |
| `vertices_capacity` | `int` | `1000` | Número de vértices para os quais se reserva espaço inicialmente. |
| `cells_capacity` | `int` | `1000` | Capacidade inicial de cada bloco de células. |
| `increase_ratio` | `float` | `1.5` | Fator de crescimento quando o espaço reservado se esgota. |
| `float_dtype` | dtype NumPy | `np.float64` | Tipo das coordenadas (`float32` ou `float64`). |
| `int_dtype` | dtype NumPy | `np.int32` | Tipo dos índices (`int32` ou `int64`). |

## Atributos

| Atributo | Descrição |
|---|---|
| `dim` | Dimensão espacial da malha. |
| `points` | Array de forma `(num_vertices, dim)`. A linha de índice `i` contém as coordenadas do vértice `i`. |
| `cells` | Blocos de células acessíveis por tipo, como `cells.triangle` e `cells.quadrilateral`. |
| `boundaries` | Dicionário que associa cada nome de fronteira aos índices ordenados dos seus vértices. |
| `num_vertices`, `num_cells` | Número de vértices e número total de células presentes na malha, respectivamente. |
| `vertices_capacity` | Capacidade atual de armazenamento de vértices. |
| `float_dtype`, `int_dtype` | Tipos NumPy das coordenadas e dos índices, respectivamente. |

## Métodos

| Método | Parâmetros | Retorno |
|---|---|---|
| `add_vertex(vertex)` | `vertex` é uma sequência de `dim` coordenadas. | Índice do novo vértice na malha (`int`). |
| `add_cell(cell_type, vertices)` | `cell_type` é `"triangle"` ou `"quadrilateral"`. `vertices` contém três ou quatro índices de vértices, na ordem de conectividade da célula. | Índice da nova célula no bloco do tipo escolhido (`int`). |

## Exemplo

```pycon
>>> from meshlab.core import Mesh

>>> mesh = Mesh(dim=2)

>>> a = mesh.add_vertex((0, 0))
>>> b = mesh.add_vertex((1, 0))
>>> c = mesh.add_vertex((0, 1))

>>> mesh.add_cell("triangle", [a, b, c])
0

>>> mesh.cells.triangle.connectivity.tolist()
[[0, 1, 2]]
```
