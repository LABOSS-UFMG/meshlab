# `Contour`

Agrupa curvas orientadas em um percurso fechado. O fim de cada curva deve coincidir com o início da seguinte, inclusive na junção da última com a primeira.

```python
meshlab.core.Contour(name, curves, tolerance=1e-10)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `name` | `str` | Obrigatório | Nome do contorno. |
| `curves` | iterável de `Curve` | Obrigatório | Curvas na ordem de percurso. |
| `tolerance` | `float` | `1e-10` | Tolerância absoluta para a coincidência dos extremos, em unidades de coordenadas. |

## Atributos

| Atributo | Descrição |
|---|---|
| `name` | Nome do contorno. |
| `curves` | Tupla de referências às curvas na ordem fornecida. |
| `tolerance` | Tolerância usada na montagem do contorno. |

## Exemplo

```pycon
>>> from meshlab.core import Contour, Curve

>>> base = Curve("base", [(0, 0), (1, 0)])
>>> lados = Curve("lados", [(1, 0), (0, 1), (0, 0)])

>>> dominio = Contour("dominio", [base, lados])

>>> [curva.name for curva in dominio.curves]
['base', 'lados']
```
