# `compute_normals`

Calcula a normal unitária à direita de cada vértice de uma frente plana orientada.

```python
meshlab.operations.compute_normals(mesh, front, method="central")
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha bidimensional que contém os vértices da frente. |
| `front` | `Front` | Frente sem ramificações, com arestas de comprimento positivo e orientação consistente. |
| `method` | `"central"` ou `"bisector"` | Define o peso das arestas no cálculo da tangente. O padrão é `"central"`. |

## Método de cálculo

**1. Calcula o vetor de cada aresta:** seja $`e=j,k`$ uma aresta orientada do vértice $`j`$ para o vértice $`k`$. Se $`\mathbf{p}_j`$ e $`\mathbf{p}_k`$ são as coordenadas desses vértices, o vetor da aresta é

```math
\mathbf{v}_{j,k} = \mathbf{p}_k - \mathbf{p}_j.
```

**2. Determina a contribuição de cada aresta:** o método `central` usa o vetor da aresta com seu comprimento original. O método `bisector` usa sua direção unitária.

```math
\mathbf{c}_{j,k} =
\begin{cases}
\mathbf{v}_{j,k}, & \text{método central},\\
\dfrac{\mathbf{v}_{j,k}}{\|\mathbf{v}_{j,k}\|}, & \text{método bisector}.
\end{cases}
```

**3. Calcula a tangente no vértice $`i`$:** em uma frente sem ramificações, há dois casos.

- **Duas arestas incidentes:** no percurso $`a \to i \to b`$, a aresta $`a,i`$ chega a $`i`$ e a aresta $`i,b`$ sai de $`i`$. Pelo passo 1, seus vetores são $`\mathbf{v}_{a,i} = \mathbf{p}_i - \mathbf{p}_a`$ e $`\mathbf{v}_{i,b} = \mathbf{p}_b - \mathbf{p}_i`$. Somam-se as duas contribuições:

```math
\mathbf{s}_i = \mathbf{c}_{a,i} + \mathbf{c}_{i,b}.
```

- **Uma aresta incidente:** se $`i`$ é um extremo aberto, há uma única contribuição, cujo sentido acompanha o percurso:

```math
\mathbf{s}_i =
\begin{cases}
\mathbf{c}_{i,b}, & \text{se } i \text{ é o vértice inicial},\\
\mathbf{c}_{a,i}, & \text{se } i \text{ é o vértice final}.
\end{cases}
```

Em ambos os casos, a tangente unitária é $`\mathbf{t}_i = \mathbf{s}_i / \|\mathbf{s}_i\|`$, desde que $`\mathbf{s}_i \ne \mathbf{0}`$.

**4. Obtem a normal à direita da frente:** a tangente está no plano $`xy`$. Seu produto vetorial com o vetor unitário $`\mathbf{e}_z = (0,0,1)`$ é

```math
\mathbf{t}_i \times \mathbf{e}_z
= (t_{i,x}, t_{i,y}, 0) \times (0, 0, 1)
= (t_{i,y}, -t_{i,x}, 0).
```

A função retorna as duas componentes no plano, que correspondem à tangente girada 90° no sentido horário:

```math
\boxed{\mathbf{n}_i = (t_{i,y}, -t_{i,x})}.
```

## Retorno

Array NumPy de forma `(N, 2)` e tipo `mesh.float_dtype`, com uma normal por vértice distinto da frente. As linhas seguem a ordem crescente dos índices dos vértices, a mesma usada por `advance_front`.

## Exemplo

Duas arestas perpendiculares, de comprimentos 2 e 1, encontram-se no vértice de índice 1. Nesse vértice, os dois métodos produzem direções distintas.

```pycon
>>> from meshlab.core import Contour, Curve, Front, Mesh
>>> from meshlab.operations import compute_normals, initialize_front, insert_contour

>>> mesh, frente = Mesh(), Front()

>>> canto = Curve("canto", [(0, 0), (2, 0), (2, 1)])
>>> volta = Curve("volta", [(2, 1), (0, 0)])

>>> insert_contour(mesh, Contour("triangulo", [canto, volta]))
>>> initialize_front(mesh, frente, ["canto"])
>>> normals = compute_normals(mesh, frente)

>>> normals[1].round(3).tolist()
[0.447, -0.894]

>>> normals = compute_normals(mesh, frente, method="bisector")

>>> normals[1].round(3).tolist()
[0.707, -0.707]

```
