# `Curve`

Representa uma curva nomeada por uma sequência ordenada de pontos. A ordem dos pontos define o sentido de percurso.

```python
meshlab.core.Curve(name, points, float_dtype=np.float64)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `name` | `str` | Obrigatório | Nome que identifica a curva como fronteira. |
| `points` | array ou sequência | Obrigatório | Coordenadas em ordem de percurso, com forma `(N, 2)` ou `(N, 3)`. |
| `float_dtype` | dtype NumPy | `np.float64` | Tipo das coordenadas (`float32` ou `float64`). |

## Atributos

| Atributo | Descrição |
|---|---|
| `name` | Nome da curva. |
| `points` | Array editável de coordenadas, inicialmente copiadas da entrada. |
| `float_dtype` | Tipo NumPy das coordenadas. |

## Exemplo

```pycon
>>> from meshlab.core import Curve
>>> parede = Curve("parede", [(0, 0), (1, 0)])
>>> parede.points.tolist()
[[0.0, 0.0], [1.0, 0.0]]
```
