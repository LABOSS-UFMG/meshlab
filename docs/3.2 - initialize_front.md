# `initialize_front`

Forma uma frente de avanço a partir de fronteiras já registradas na malha.

```python
meshlab.operations.initialize_front(mesh, front, curves, guides=())
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha cujas fronteiras fornecem os índices dos vértices. |
| `front` | `Front` | Frente que recebe as arestas orientadas. |
| `curves` | sequência de `str` | Nomes das fronteiras selecionadas, em ordem de percurso. |
| `guides` | sequência de `str`, opcional | Nomes das fronteiras retas de comprimento positivo que guiam os extremos da frente. O padrão é uma sequência vazia. |

## Método

Cada par de índices consecutivos de uma mesma fronteira forma uma aresta orientada. Os extremos abertos são os vértices que aparecem em uma única aresta. Quando uma guia contém o índice de um desses extremos, a função associa o extremo à guia.

## Resultado

Retorna `None`. As arestas ficam em `front.entities.edge`, e o dicionário `front.constraints["guides"]` associa os índices dos extremos guiados aos nomes das guias.

## Exemplo

```pycon
>>> from meshlab.core import Contour, Curve, Front, Mesh
>>> from meshlab.operations import initialize_front, insert_contour

>>> mesh = Mesh()

>>> base = Curve("base", [(0, 0), (1, 0)])
>>> guia = Curve("guia", [(1, 0), (1, 1)])
>>> lado = Curve("lado", [(1, 1), (0, 0)])

>>> insert_contour(mesh, Contour("triangulo", [base, guia, lado]))
>>> frente = Front()
>>> initialize_front(mesh, frente, ["base"], guides=["guia"])

>>> frente.entities.edge.tolist(), frente.constraints["guides"]
([[0, 1]], {1: 'guia'})
```
