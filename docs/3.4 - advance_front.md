# `advance_front`

Gera uma camada de quadriláteros e atualiza a frente para o próximo passo.

```python
meshlab.operations.advance_front(mesh, front, normals, height)
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha bidimensional que recebe os vértices e quadriláteros da nova camada. |
| `front` | `Front` | Frente orientada que será atualizada. |
| `normals` | array de forma `(N, 2)` | Direção unitária em cada um dos `N` vértices distintos da frente, em ordem crescente de índice. |
| `height` | `float` ou array de forma `(N,)` | Altura positiva da camada, uniforme ou individual por vértice, na mesma ordem das normais. |

## Método de cálculo

Para cada vértice de posição `p`, a nova posição é `q = p + h * n`, em que `h` é a altura e `n` é a normal fornecida. Quando o vértice é um extremo guiado, a função projeta `q` na reta da guia. A projeção pode alterar a distância percorrida, e cabe ao usuário escolher uma altura que mantenha o extremo no segmento e evite colisões.

Cada vértice distinto da frente gera um novo vértice. Para cada aresta `(a, b)`, a função insere o quadrilátero `[a, novo_a, novo_b, b]`. A aresta `(novo_a, novo_b)` passa a compor a frente seguinte.

## Resultado

Retorna `None`. Os novos vértices e células ficam em `mesh`, e `front` passa a referenciar a borda da camada gerada. Os extremos guiados são registrados nas respectivas fronteiras. As normais devem ser recalculadas antes do próximo avanço.

## Exemplo

Em uma aresta horizontal orientada da esquerda para a direita, a normal aponta para baixo. Um passo de altura 0,5 gera um quadrilátero.

```pycon
>>> from meshlab.core import Contour, Curve, Front, Mesh
>>> from meshlab.operations import advance_front, compute_normals, initialize_front, insert_contour

>>> mesh, frente = Mesh(), Front()

>>> base = Curve("base", [(0, 0), (1, 0)])
>>> lados = Curve("lados", [(1, 0), (0, 1), (0, 0)])

>>> insert_contour(mesh, Contour("triangulo", [base, lados]))
>>> initialize_front(mesh, frente, ["base"])
>>> normals = compute_normals(mesh, frente)
>>> advance_front(mesh, frente, normals, height=0.5)

>>> mesh.cells.quadrilateral.num_cells
1
>>> mesh.points[frente.entities.edge[0]].tolist()
[[0.0, -0.5], [1.0, -0.5]]
```
