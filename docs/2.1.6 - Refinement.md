# `Refinement`

Define o tamanho local dos elementos em torno de uma geometria de referência e a largura da transição até o tamanho da malha fora da região refinada.

```python
meshlab.core.Refinement(geometry, size, distance=0.0, transition=1.0)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `geometry` | `Point`, `Curve` ou `Contour` | Obrigatório | Ponto, curva ou contorno fechado que define a região de interesse. Para um contorno, o refinamento inclui seu interior. |
| `size` | `float` | Obrigatório | Tamanho desejado dos elementos na região refinada. Deve ser positivo. |
| `distance` | `float` | `0.0` | Distância adicional com tamanho constante em torno da geometria. Aceita zero. |
| `transition` | `float` | `1.0` | Largura positiva da faixa de transição. |

## Atributos

| Atributo | Descrição |
|---|---|
| `geometry` | Referência à geometria escolhida. |
| `size` | Tamanho local dos elementos. |
| `distance` | Extensão da faixa de tamanho constante. |
| `transition` | Largura da transição para o tamanho externo. |

## Exemplo

```pycon
>>> from meshlab.core import Point, Refinement
>>> origem = Point("origem", [0, 0])
>>> refino = Refinement(origem, size=0.05, distance=0.2)
>>> refino.geometry.name, refino.size
('origem', 0.05)
```
