# `insert_contour`

Insere um contorno fechado na malha e registra os índices dos vértices de cada curva sob seu nome de fronteira.

```python
meshlab.operations.insert_contour(mesh, contour)
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha que recebe os vértices. Sua dimensão deve coincidir com a das coordenadas do contorno. |
| `contour` | `Contour` | Curvas orientadas em ordem de percurso, com extremos coincidentes nas junções. Cada curva deve ter pelo menos dois pontos e um nome único na malha. |

## Método

A função percorre as curvas em ordem e insere seus pontos na malha. Em cada junção, o início da curva reutiliza o índice do fim da curva anterior. O último ponto do contorno reutiliza o primeiro índice, fechando o percurso.

## Resultado

Retorna `None`. A malha passa a conter os novos vértices, e `mesh.boundaries` associa cada nome de curva aos seus índices ordenados.

## Exemplo

```pycon
>>> from meshlab.core import Contour, Curve, Mesh
>>> from meshlab.operations import insert_contour

>>> mesh = Mesh()

>>> base = Curve("base", [(0, 0), (1, 0)])
>>> lados = Curve("lados", [(1, 0), (0, 1), (0, 0)])

>>> insert_contour(mesh, Contour("triangulo", [base, lados]))

>>> mesh.boundaries["base"].tolist(), mesh.boundaries["lados"].tolist()
([0, 1], [1, 2, 0])
```
