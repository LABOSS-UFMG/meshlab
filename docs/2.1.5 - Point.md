# `Point`

Representa um ponto geométrico nomeado em duas ou três dimensões. Pode servir de referência para o refinamento local.

```python
meshlab.core.Point(name, coordinates, float_dtype=np.float64)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `name` | `str` | Obrigatório | Identificador do ponto. |
| `coordinates` | array ou sequência | Obrigatório | Duas ou três coordenadas finitas. |
| `float_dtype` | dtype NumPy | `np.float64` | Tipo das coordenadas (`float32` ou `float64`). |

## Atributos

| Atributo | Descrição |
|---|---|
| `name` | Nome do ponto. |
| `coordinates` | Vetor editável de coordenadas, inicialmente copiadas da entrada. |
| `float_dtype` | Tipo NumPy das coordenadas. |

## Exemplo

```pycon
>>> from meshlab.core import Point
>>> origem = Point("origem", [0, 0])
>>> origem.coordinates.tolist()
[0.0, 0.0]
```
