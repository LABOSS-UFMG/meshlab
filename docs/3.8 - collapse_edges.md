# `collapse_edges`

Reduz o número de vértices de uma frente plana. Cada grupo de arestas conectadas que satisfaz os critérios de colapso é substituído por um vértice no centroide do grupo. A função atualiza a malha e a frente e devolve um mapa dos índices originais para os finais.

```python
meshlab.operations.collapse_edges(mesh, front, edges)
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha bidimensional cujos vértices, células e índices de fronteira serão atualizados. |
| `front` | `Front` | Frente a atualizar. Cada componente deve ser uma cadeia aberta ou um laço fechado, sem ramificações. |
| `edges` | sequência de pares de inteiros | Arestas candidatas da frente, expressas pelos índices dos vértices antes do colapso. Podem ser obtidas com [`find_short_edges`](3.7%20-%20find_short_edges.md). |

## Método de cálculo

**1. Agrupa as arestas candidatas.** Arestas ligadas por um vértice pertencem ao mesmo grupo. Por exemplo, as arestas $(a,b)$ e $(b,c)$ formam um grupo com três vértices distintos. Os grupos são processados em ordem crescente de seu menor índice original, independentemente da ordem de entrada.

**2. Calcula a posição proposta.** Seja $G$ o conjunto dos vértices distintos do grupo. O vértice de menor índice representa o grupo e recebe, se o colapso for aceito, a média das coordenadas originais. Cada vértice contribui uma vez, mesmo quando pertence a várias arestas candidatas.

$$
\mathbf{p}_G = \frac{1}{|G|}\sum_{i\in G}\mathbf{p}_i.
$$

**3. Avalia o grupo inteiro.** O colapso precisa atender aos seguintes critérios:

- **Proteção das fronteiras.** Todos os vértices do grupo devem estar fora das fronteiras físicas de `mesh.boundaries` e dos extremos guiados de `front.constraints["guides"]`.
- **Continuidade da frente.** Após o colapso, a componente afetada deve manter pelo menos três vértices se for fechada, ou dois se for aberta.
- **Validade das células incidentes.** A função substitui os índices do grupo pelo representante e elimina repetições consecutivas na conectividade, inclusive na junção do último vértice com o primeiro. Repetições não consecutivas invalidam o grupo. Cada célula que conservar pelo menos três vértices deve permanecer estritamente convexa e manter sua orientação, considerando a tolerância numérica. Uma célula com menos de três vértices é removida se o grupo for aceito.

Se algum critério falhar, o grupo inteiro é ignorado e o processamento segue para o próximo. A avaliação geométrica é local às células incidentes.

**4. Atualiza a malha e a frente.** Para cada grupo aceito, a função move o representante para o centroide e remove da frente as arestas cujos extremos passaram a coincidir. Ao final, compacta os índices uma única vez, reconstrói os blocos de células e remapeia as fronteiras físicas, as arestas da frente e seus extremos guiados. Um quadrilátero reduzido a três vértices passa ao bloco de triângulos.

## Retorno

Array de tipo `mesh.int_dtype`, com uma entrada para cada vértice original. Se `mapa[i] == j`, o vértice de índice original `i` é representado pelo índice final `j`. Se a lista de candidatas estiver vazia ou todos os grupos forem rejeitados, o mapa é a identidade.

Se houver outras frentes na mesma malha, use o mapa para atualizar seus índices de arestas e de extremos guiados. Antes do próximo avanço, recalcule as normais da frente alterada.

## Exemplo

Uma frente fechada acompanha os quatro lados de um quadrilátero. O colapso da aresta curta $(0,1)$ une seus extremos no ponto $(0{,}1, 0)$ e transforma o quadrilátero em um triângulo.

```pycon
>>> from meshlab.core import Front, FrontEntities, Mesh
>>> from meshlab.operations import collapse_edges, find_short_edges
>>> mesh = Mesh()
>>> vertices = [mesh.add_vertex(p) for p in [(0, 0), (0.2, 0), (1, 1), (0, 1)]]
>>> mesh.add_cell("quadrilateral", vertices)
0
>>> frente = Front(entities=FrontEntities(edge=[(0, 1), (1, 2), (2, 3), (3, 0)]))
>>> arestas = find_short_edges(mesh, frente, min_length=0.3)
>>> mapa = collapse_edges(mesh, frente, arestas)
>>> mapa.tolist()
[0, 0, 1, 2]
>>> mesh.points[mapa[0]].tolist()
[0.1, 0.0]
>>> mesh.cells.triangle.connectivity.tolist()
[[0, 1, 2]]

```
