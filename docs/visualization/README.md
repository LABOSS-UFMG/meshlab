# Visualização

A implementação está em `meshlab/utils/plot_mesh.py`, importada por `from meshlab.utils import plot_mesh`. Ver [parâmetros e desenho](../utils/plot_mesh.md).

Não existe módulo ativo `meshlab/visualization/` nesta versão. A visualização da malha final exportada é opcional, por `export_mesh(..., show=True)`.
