# `Front`

Representa uma frente de avanço por arestas orientadas. Cada aresta referencia dois vértices da malha pelos seus índices.

```python
meshlab.core.Front(name="front", entities=None, int_dtype=np.int32)
```

## Parâmetros

| Parâmetro | Tipo | Padrão | Descrição |
|---|---|---|---|
| `name` | `str` | `"front"` | Identificador da frente. |
| `entities` | `FrontEntities` ou `None` | `None` | Conectividade inicial com forma `(N, 2)`. Por padrão, a frente começa vazia. |
| `int_dtype` | dtype NumPy | `np.int32` | Tipo dos índices (`int32` ou `int64`). |

## Atributos

| Atributo | Descrição |
|---|---|
| `name` | Nome da frente. |
| `entities` | Arestas acessíveis por `entities.edge`. Cada linha contém os índices de origem e destino. |
| `constraints` | Dicionário de restrições, como as guias associadas aos extremos da frente. |
| `int_dtype` | Tipo NumPy dos índices de vértices. |

## Exemplo

```pycon
>>> from meshlab.core import Front

>>> frente = Front("parede")

>>> frente.entities.edge.shape
(0, 2)
```
