# `smooth_normals`

Aplica um passo de suavização às normais de uma frente plana. Em cada vértice, a função combina a normal original com a média das normais vizinhas e calcula quanto a direção girou.

```python
meshlab.operations.smooth_normals(mesh, front, normals, relaxation=0.5)
```

## Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `mesh` | `Mesh` | Malha bidimensional que define o tipo numérico dos cálculos por meio de `mesh.float_dtype`. |
| `front` | `Front` | Frente sem ramificações. Suas arestas identificam os vizinhos de cada vértice. |
| `normals` | array de forma `(N, 2)` | Normais unitárias dos `N` vértices distintos da frente, em ordem crescente de índice, como no retorno de `compute_normals`. |
| `relaxation` | `float` ou array de forma `(N,)` | Peso entre 0 e 1 atribuído à média das normais vizinhas. Pode ser uniforme ou individual por vértice, na mesma ordem de `normals`. O padrão é `0.5`. |

## Método de cálculo

**1. Calcula a média das normais vizinhas.** Seja $`\mathbf{n}_i`$ a normal original no vértice $`i`$. Em um vértice com **duas arestas incidentes**, os vizinhos $`a`$ e $`b`$ têm o mesmo peso. Em um **extremo aberto**, a média é a própria normal do único vizinho $`j`$.

```math
\mathbf{m}_i =
\begin{cases}
(\mathbf{n}_a+\mathbf{n}_b)/2, & \text{se os vizinhos são } a \text{ e } b,\\[4pt]
\mathbf{n}_j, & \text{se o único vizinho é } j.
\end{cases}
```

**2. Combina as direções e normaliza o resultado.** Com o peso de relaxação $`\alpha_i`$, a direção intermediária $`\mathbf{q}_i`$ e a nova normal unitária $`\mathbf{n}'_i`$ são dadas por

```math
\mathbf{q}_i=(1-\alpha_i)\mathbf{n}_i+\alpha_i\mathbf{m}_i,
\qquad
\mathbf{n}'_i=\frac{\mathbf{q}_i}{\|\mathbf{q}_i\|}.
```

Com $`\alpha_i=0`$, o vértice mantém sua direção. Com $`\alpha_i=1`$, assume a direção da média dos vizinhos. A normalização exige $`\mathbf{q}_i\ne\mathbf{0}`$. O passo é simultâneo: todos os vértices usam as normais originais dos vizinhos.

**3. Calcula a rotação da normal.** O ângulo de rotação $`\Delta\theta_i`$ é medido da normal original para a nova normal. O produto escalar fornece o cosseno desse ângulo, e o determinante fornece o seno.

```math
c_i=\mathbf{n}_i\cdot\mathbf{n}'_i,
```

```math
d_i=n_{i,x}n'_{i,y}-n_{i,y}n'_{i,x},
```

```math
\Delta\theta_i=\text{atan2}(d_i,c_i).
```

Uma rotação anti-horária tem sinal positivo. Uma rotação horária tem sinal negativo.

## Retorno

A função retorna dois arrays de tipo `mesh.float_dtype`, na mesma ordem dos vértices de entrada.

| Saída | Forma | Descrição |
|---|---|---|
| `new_normals` | `(N, 2)` | Novas normais unitárias após um passo de suavização. |
| `rotation` | `(N,)` | Rotação de cada normal em radianos, com valores entre $`-\pi`$ e $`\pi`$. |

## Exemplo

Em uma frente aberta em L com dois segmentos de mesmo comprimento, a normal do canto fica entre as normais dos extremos. Com relaxação de 0,5, os extremos giram 22,5° em sentidos opostos e a normal do canto mantém sua direção.

```pycon
>>> import numpy as np
>>> from meshlab.core import Contour, Curve, Front, Mesh
>>> from meshlab.operations import compute_normals, initialize_front, insert_contour, smooth_normals

>>> mesh, frente = Mesh(), Front()

>>> canto = Curve("canto", [(0, 0), (1, 0), (1, 1)])
>>> volta = Curve("volta", [(1, 1), (0, 0)])

>>> insert_contour(mesh, Contour("triangulo", [canto, volta]))
>>> initialize_front(mesh, frente, ["canto"])

>>> normais = compute_normals(mesh, frente)
>>> suavizadas, rotacao = smooth_normals(mesh, frente, normais)

>>> suavizadas.round(3).tolist()
[[0.383, -0.924], [0.707, -0.707], [0.924, -0.383]]
>>> np.degrees(rotacao).round(1).tolist()
[22.5, 0.0, -22.5]

```
